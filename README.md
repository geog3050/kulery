# SEES 3050 — Geospatial Programming  
**Fall 2026 • University of Iowa**  
**Instructor: Dr. Caglar Koylu**

This repository contains my coursework, experiments, and project development for **SEES:3050 – Geospatial Programming** at the University of Iowa. The class integrates Python programming with GIS concepts, ArcGIS Pro workflows, and ArcPy automation. My personal focus throughout the semester is building **object‑oriented, reproducible geospatial workflows** that support my broader research interests in spatial analysis, demographic data, and GIS-based modeling.

---

## 📌 Course Context 

SEES 3050 teaches how to think like a geospatial programmer — not just how to run tools. The syllabus emphasizes:

- Python fundamentals (syntax, control flow, functions, modules)  
- Data structures (lists, dictionaries, nested structures)  
- ArcPy geoprocessing and automation  
- Spatial analysis concepts (projections, interpolation, raster processing)  
- GIS modeling and PySAL  
- Building professional, reproducible workflows

A line from the syllabus that captures the spirit of the course:  
> “Geographic Information Science (GIScience) provides essential tools and methods for addressing societal and environmental challenges.”

This repository documents how I’m developing those tools and methods through code, assignments, and a final project.
